# Лабораторная работа № 2 — поиск MAC-адресов

Трещев Олег Денисович, ИДБ-25-15.

Программа проверяет введённый MAC-адрес и ищет адреса в текстовом файле или
на веб-странице. Принимаются шесть пар шестнадцатеричных цифр с одинаковым
разделителем `:` или `-`. Поиск выводит уникальные адреса в формате с `:`.
После поиска результаты можно сохранить в текстовый файл.

Запуск: `python main.py`. Нужен Python 3, сторонние библиотеки не требуются.
Для поиска по URL нужен доступ в интернет; читается не больше 1 МБ страницы.

Тесты: `python -m unittest -v`.
